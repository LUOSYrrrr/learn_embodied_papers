1 · 它究竟比普通 joint WAM 多学了什么？

先把问题具体化

“预测视频能帮助控制”已经不是新问题。这里追问：若未来视频只能看噪声动作，模型是否真正学到给定这个确定动作，世界会怎样变？反过来，让世界模型也学选动作，会不会损害视频质量？作者在同一架构中切换条件，尽量隔离这两种监督的作用。

论文五问与直接依赖 · §1–3，pp.1–5
问题答案
背景 / 卡点视频先验有效，但“视频与动作一起去噪”不自动等于“学习指定动作的前向动力学”。动作太噪或被 mask，动作到视觉的条件就不明确。

2 · 主干图：训练的信息流不等于部署调用顺序

从“联合”走到实际可见性

上一节说明动作有两种角色。现在拆开图中各流：图像先编码，两个专家各自处理 token，联合注意力用 mask 规定能读取谁。这里的关键不是 MoT 名字，而是动作是否能访问未来。

  1. 真实输入：已观察图像前缀和语言指令。视频 VAE 编码观察；图像前缀不加噪。
  2. 训练目标：未来视频 latent 与对应动作块。视频、动作噪声水平独立采样；依动作模式保留全体、前缀或零个干净动作。
  3. 内部交互：未来视频读取截至本时段的视频/动作；动作只读取真实观察和截至本时段的动作，不读未来视频。
  4. 反向传播：视频损失通过可见动作特征和共享观察表征提供额外训练信号。不存在“动作推理必须读取未来图像”的逻辑要求。
  5. 策略部署：最新真实观察→复用观察表征→从噪声生成动作块→执行→再次观察；不生成未来视频。
§3.2 Eq.2、§3.5，pp.4–6；Appendix A.1 p.16 明确写部署不生成未来视频。该结论来自 mask 与部署说明，而不是由 MoT 类别推断。

3 · 六个公式：符号、用途与手算例子

两套时间别混淆

下文 i/k 是轨迹中的时间块或动作位置；τ 是去噪进度。τ 从 1 到 0 不意味着机器人倒着走。所有数字算例均为教学例子，不是论文实验。

Eq.1 · 一个模型的两个问题

pθ(zfut | C, a)；pθ(a | C)，C=(zctx, ℓ)
θ / p
网络参数 / 条件分布；生成模型可以对同一条件产生多个合理结果。
zctx / zfut
已观察图像 / 未来图像经 VAE 编码的 latent token 序列。具体空间 token 数随视频设置变化，本文未逐项列出。
a / ℓ
a=(a₁,…,aK) 是 K 步连续动作块，形状可写 K×dₐ；ℓ 是语言指令。dₐ 未在本文协议中逐基准完整列出。
教学例：C 是“看到抽屉关着＋打开抽屉”。左式给定“夹住把手、后拉”的动作，问未来画面；右式不给动作，要求模型自己生成控制序列。不是先算左式才能算右式。

Eq.2 · 为什么动作不需要未来视频？

Sᵥ(i)=V≤ᵢ ∪ A≤ᵢ；Sₐ(i)=V₀ ∪ A≤ᵢ

V₀ 是观察，Vᵢ 是第 i 个未来视频块，Aᵢ 是对齐动作段；S 是该 Query 可见的 Key 集合。视频可以看已经对齐的动作，动作则只能看观察和动作前缀；块内允许自由交互，块间遵循时序。观察 Query 只留在观察流内。

i=2 时，V₂ 可读 V₀/V₁/V₂、A₁/A₂；A₂ 可读 V₀、A₁/A₂，不能读 V₁/V₂，也不能读 A₃。因果粒度是块，不是说同一块内每个 token 严格自回归。

Eq.3 · 联合 attention 到底联合在哪里？

Uₘ=softmaxSₘ(QₘKᵀ/√d)V；K=[Kᵥ;Kₐ]，V=[Vᵥ;Vₐ]

m 表示视频或动作专家；Q/K/V 是各专家投影得到的查询、键、值，不是原始像素。d 是每个 attention head 的键维度。拼接发生在 token 轴，各路仍有自己的参数。mask 让不可见项的权重归零，再对可见项归一化。

某动作 Query 与三个 Key 的打分相同，但其中一个是未来视频而被屏蔽：输出权重变为 [0.5,0.5,0]，不是 [⅓,⅓,⅓]。“联合 attention”不能绕过这条屏蔽。

Eq.4 · 只修改“哪些动作已知”

aₖ(r,τ) = aₖ（k≤r）；否则为 ãₖ(τ)

r 是干净前缀长度，取 0…K。r=K 学指定动作下的世界；r=0 学完整策略；中间值学动作续写。干净 token 的 noise embedding 为零；后缀使用同一个采样的动作噪声水平。partial-clean 在对齐块边界附近与全范围均匀采样之间混合；具体二者比例未给出。

K=4、r=2：输入 [a₁,a₂,ã₃,ã₄]。只有 a₃/a₄ 是动作去噪考题；a₁/a₂ 是条件，不能把它们也算进同一动作损失平均。

Eq.5 · flow matching 与两项损失

x(τ)=(1−τ)x+τε；目标速度=ε−x
Lᵥ=E[wᵥ‖ûᵥ−(εᵥ−zfut)‖²mean]
Lₐ=Er<K[wₐ‖ûₐ,>r−(εₐ,>r−a>r)‖²mean]
L=λᵥLᵥ+λₐLₐ

x 是干净目标，ε 是同形状高斯噪声；û 是模型预测的速度场。w 是随噪声水平变化的损失权重，λ 平衡模态。视频和动作各自采样 τ。动作损失只平均有后缀的样本；all-clean 没有动作去噪损失。具体 λ、w 配方未完整报告，不能默认都为 1。

标量 x=2、ε=0、τ=0.75，则输入 0.5、目标速度 −2。若预测 −1.5，平方误差为 0.25。生成从 τ=1 向 0 积分，步长为负，所以负速度沿这条积分方向会使值靠近 2；不能按正时间步直觉判断符号。

Eq.6 · 纯想象中的闭环

Cⱼ=(E(ôⱼ),ℓ)
âⱼ~p(a|Cⱼ)；ẑⱼfut~p(zfut|Cⱼ,âⱼ)
ôⱼ₊₁=last(D(ẑⱼfut))

E/D 是 VAE 编/解码，帽子表示生成值；j 是想象轮次。第一步生成动作，第二步把这些动作固定为干净条件预测视频，再取各相机末帧作下一轮观察。两个调用使用同一网络，不是同一次生成中用未来视频去修正当前动作。

第 1 轮梦见抽屉打开；第 2 轮以“抽屉已打开”的生成画面继续取物。若第一轮幻觉打开了但真实抽屉没动，之后梦境可以自洽却与现实脱节。这就是为什么 Figure 8 不是实际任务成功率。
检查理解：all-clean 样本不训练动作损失，为什么仍能改善策略？

它训练了策略复用的观察/交互表征，且视频能读取动作特征，梯度可以影响相连的专家。改善效果由内部对照支持；“哪一类表示变化占主要贡献”仍是机制解释，并没有被独立因果实验完全证明。

6 · 策略反过来真的改善了世界预测吗？

先固定评测条件

WM 和 OneWM 都拿到同一干净动作，预测未来多视角视频。差别在训练时有没有动作生成监督。这样才是在问“动作学习能否帮助世界模型”，而不是让两者拿到不同输入。

Appendix A：指标实现会影响可比性

每个 chunk 8 个未来帧，不含条件帧；LIBERO/Plus 32 动作步、图像 stride 4；RoboCasa 16 步、stride 2。PSNR=−10log₁₀(MSE+10⁻⁸)，RGB 范围 [0,1]；SSIM 用 11×11 高斯窗口；LPIPS 用 PIQ VGG16。FID/FVD 先 H.264 QP20、YUV420p 编解码，分别提取 Inception-v3 2048D 与 Kinetics-400 I3D-R50 的 400D logits。后者不是可随意与其他 FVD 实现混比的通用标尺。

教学例：MSE=.01 时 PSNR≈20 dB；MSE 减半为 .005 时约 23.01 dB。提高 3 dB 接近误差减半，但不意味着机器人成功率翻倍。

8 · Appendix C：无尽梦境的证据上限

这是论文中唯一把两个推理模式交替接起来的展示。它没有再训练、也没有真实环境的每轮纠错。可支持“模型可以自生成连续的动作—视觉序列”；不支持“25.6 秒任务都能在真机成功”“已有可靠规划搜索”或“无需环境验证”。

9 · 细读后的 insight、冲突与研究边界

Claim → mechanism → evidence → boundary
主张机制证据不能外推
世界帮助动作指定干净控制的前向预测，改变共享表示与梯度Table 1；Fig 4；内控固定训练预算不是所有 OOD 维度更好；未见组合仍 7%
动作帮助世界动作生成监督约束控制相关几何Table 2，同架构 WM 对照LIBERO FID 退步；表征因果路径未单独量化
两种能力可组合策略/世界接口轮流调用Eq.6、Appendix C 六例没有梦境准确率、真实长程成功率或规划收益

与 VLA / Embodied AI 的联系：最值得复用的是训练问题的设计：世界模型是否真的看见足够清晰的动作因果条件？辅助视觉损失是否在不增加部署成本时提供更好的控制表征？这比把“联合生成”当成固定架构标签更可操作。

原文表述核对：§4.2 说对 Fast-WAM 在所有 Plus 类别都更好，但 Table 1 光照为 OneWM 79.86、Fast-WAM 78.90，确实成立；对内部 WAMmask 光照则退步，不能把这两句话混用。arXiv 页边日期 10-15 与正文 Date 10-16 并存，元信息保留差异。不同论文里的 LIBERO-Plus 数字不能直接并榜，版本/任务/评测协议须另外核验。

可支持的最强结论：在这套 Wan 初始化的因果 MoT 与所测试预算下，加入明确动作条件的世界学习能改善策略，加入策略学习能改善多数世界预测指标。暂不能支持：任意规模的 scaling law、强跨本体迁移、普遍实时性，或未来想象是部署动作的必要条件。
