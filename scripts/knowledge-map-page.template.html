World Model ≠ WAM

World Model 侧重世界如何变化；动作条件动力学常写成“当前状态 + 动作 → 未来”。WAM 将未来预测与动作生成／提取结合，可以是级联，也可以是联合模型。WAM 不是纯预测模型的同义词；不同论文边界不完全统一。

VLA 与 WAM 可以交叠

VLA 强调视觉、语言与动作的策略接口；WAM 强调预测与行动的结合。因此不把它们画成严格互斥集合。生成视频的方法也不自动拥有可控动力学，JEPA 则不必生成像素。

训练方法不是模型的子模块

同一个 VLA 或 WAM 可以用模仿学习、RL 或上下文适应。ICL 更新上下文，TTT 更新参数；DAgger 聚合专家监督，不能因交互就归为 RL。3D/4DGS 是表示与渲染，不等同物理仿真。
